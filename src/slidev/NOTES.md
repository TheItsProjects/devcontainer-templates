## Information

This template contains a development container configuration for [Slidev](https://sli.dev/), a tool for creating presentations using Markdown. The configuration sets up a Node.js environment with Slidev and includes recommended VS Code extensions for an enhanced development experience.

## Features

-   Node.js environment with Slidev installed
-   Pre-configured VS Code settings for Markdown editing
-   Automatic formatting using prettier with Slidev plugin
-   VS Code task for formatting and preserving Slidev slides
-   Post-start command to guide users on how to start presenting
-   Optionally providing a starter `slides.md` file for quick setup
