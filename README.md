# TheItsProjects Devcontainer Templates

A collection of development container templates for various frameworks and tools to streamline your development environment setup.

## Slidev Template

This template contains a development container configuration for [Slidev](https://sli.dev/), a tool for creating presentations using Markdown. The configuration sets up a Node.js environment with Slidev and includes recommended VS Code extensions for an enhanced development experience.

Obtain the Slidev template by using the following url when setting up a new development container in VS Code:

```
ghcr.io/theitsprojects/devcontainer-templates/slidev:latest
```
